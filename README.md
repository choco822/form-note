# フォーム解析ノート（チーム共有・仮バージョン）

打撃・投球の動画から、骨格をAIで推定して角度と大事な瞬間（前足の着地、インパクト／リリース）を取り出し、チームで記録を共有するWebアプリです。

- 動画はスマホの中だけで処理され、どこにもアップロードされません
- 記録（数値・骨格・小さな静止画1枚）はFirebaseに保存されます
- **ログインは不要**です。アプリを開いた人は全員、チーム全員の記録を見る・保存する・消すことができます

> **仮バージョンの注意**：公開URLを知っている人なら誰でも記録を見られます（選手の写った小さな静止画も含みます）。URLはチームの中だけで共有し、SNSなどには載せないでください。

---

## 公開までの手順（30分ほど）

パソコンでの作業をおすすめします。このフォルダ（zipを展開したもの）を手元に置いて進めてください。

### 1. Firebaseのプロジェクトを作る

1. <https://console.firebase.google.com/> をGoogleアカウントで開く
2. 「プロジェクトを作成」（または「プロジェクトを追加」）を押す
3. 名前を入れる（例：`form-note-team`）。Googleアナリティクスはオフでかまいません
4. 「プロジェクトを作成」を押して、できるまで待つ

### 2. ログインとデータベースを有効にする

**ログイン（Authentication）**

1. 左のメニューの「構築」→「Authentication」→「始める」
2. 「ログイン方法」で「**匿名**」を選び、スイッチを有効にして「保存」

> アプリを開いたスマホごとに、見えないところで自動的にログインする仕組みです。チームの人がメールアドレスやパスワードを入れる必要はありません。アプリを通さない直接のアクセスを断るために使っています。

**データベース（Firestore）**

1. 左のメニューの「構築」→「Firestore Database」→「データベースを作成」
2. ロケーションは `asia-northeast1（東京）` を選ぶ
3. 「本番環境モードで開始」を選んで作成する
4. 上の「ルール」タブを開き、最初から書いてある内容をすべて消して、このフォルダの **`firestore.rules` の中身をまるごと貼り付け**、「公開」を押す

> ルールは「誰がどのデータを見られるか」を決める大事な設定です。貼り忘れると、アプリが記録を読み書きできません。

### 3. アプリとFirebaseをつなぐ

1. 左上の歯車 →「プロジェクトの設定」
2. 下のほうの「マイアプリ」で、ウェブのアイコン（`</>`）を押す
3. アプリのニックネームを入れて「アプリを登録」（Firebase Hostingのチェックは不要）
4. 表示される `const firebaseConfig = { ... }` の中の値を、このフォルダの **`config.js`** の同じ名前の欄に貼り付けて保存する

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIza...",
  authDomain: "form-note-team.firebaseapp.com",
  projectId: "form-note-team",
  storageBucket: "form-note-team.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef",
};
```

> この値は公開されても問題ありません。データを守っているのは手順2で貼ったルールです。

### 4. GitHub Pagesで公開する

1. <https://github.com/> にログインし、右上の「＋」→「New repository」
2. Repository name を入れる（例：`form-note`）。**Public** を選んで「Create repository」
3. 表示されたページの「uploading an existing file」を押す
4. このフォルダの**中身をすべて**（`index.html`、`config.js`、`js`、`pose_s`、`pose_n`、`icons` などのフォルダも含めて）ドラッグ＆ドロップし、下の「Commit changes」を押す
   - ChromeかEdgeなら、フォルダごとドラッグできます
5. リポジトリの「Settings」→ 左の「Pages」→「Branch」で `main` と `/ (root)` を選んで「Save」
6. 数分待つと、ページの上に公開URL（`https://ユーザー名.github.io/form-note/`）が表示されます

### 5. 選手の名簿を作る

1. 公開URLをスマホで開く（ログイン画面は出ずに、そのまま使えます）
2. 下の「記録」→ いちばん下の「選手の名簿」で、選手の名前を入れて「追加」
3. 解析や球速を保存するときに、この名簿から選手を選びます

名簿はチーム全員で共有されるので、誰か1人が作ればOKです。

### 6. チームに配る

- 公開URLをLINEなどで送るだけです（登録は不要です）
- **ホーム画面に追加**すると、アプリのようにアイコンから開けます
  - iPhone：Safariで開く →「共有」ボタン →「ホーム画面に追加」
  - Android：Chromeで開く → 右上のメニュー →「ホーム画面に追加」または「アプリをインストール」

## 使い方のポイント

- **選手の選び方**：解析・球速の保存のときに、名簿から誰の記録にするかを選びます。名簿にいない選手は「＋名簿に追加」から追加できます
- **記録を消すとき**：「消す」を押すと「本当に消す」に変わるので、もう一度押します。名簿から選手を消しても、その選手の記録は残ります
- **画面に何人か映っているとき**：解析の前に「追いかける選手」をタップで選びます
- **アプリ内カメラ**：「アプリ内カメラで撮る」で、アプリの中で撮影してそのまま解析できます。スローモーションで撮りたいときは、カメラアプリで撮ってから「動画を選ぶ」で読み込んでください
- **AIの読み込み**：最初の1回だけ約20MBをダウンロードします。2回目以降はスマホに保存されたものを使います

## 更新のしかた

ファイルを直したら、GitHubのリポジトリで「Add file」→「Upload files」から同じ名前のファイルをアップロードし直します。数分でアプリに反映されます。`config.js` は自分の設定を入れたものを使い続けてください。

`firestore.rules` が変わったときは、Firebaseの「Firestore Database」→「ルール」に中身を貼り直して「公開」も押してください（例：短い動画を保存できるようにした更新）。

## 無料で使える範囲の目安

（2026年10月時点の目安。条件は変わることがあるので、各サービスの最新の案内を確認してください）

- **Firestore（無料のSparkプラン）**：1日あたり読み取り5万件・書き込み2万件、保存1GBまで。アプリを開くたびに全員分の記録を読み込むので、記録が数千件になったら注意してください
- **記録に付ける短い動画**：1本0.3MBほど（Firestoreの中では文字にするので約0.4MB）。保存1GBのうち、動画だけなら2,000本ほどが目安です。記録を消すと、その動画もいっしょに消えて容量が空きます
- **GitHub Pages**：サイト全体で1GBまで、転送量は月100GBが目安。AIモデルは1人あたり最初の1回だけ約20MBです

## 困ったとき

| 症状 | 確認すること |
|---|---|
| 「Firebaseの設定がまだです」と出る | `config.js` に値を貼ってアップロードし直したか |
| 「チームの記録につなげませんでした」と出る | 手順2で「匿名」ログインを有効にしたか |
| 記録や名簿が出てこない・保存できない | 手順2のルールを貼って「公開」したか |
| 保存のときに「選手を追加して」と出る | 「記録」画面の名簿に選手を追加して、選んでから保存する |
| カメラが使えない | ブラウザの設定でカメラを許可したか。だめなら「撮影する」ボタンを使う |
| 解析がとても遅い | 「AIの精度」を「速さ優先」にする。古い機種では時間がかかります |

## 中身の構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面 |
| `js/app.js` | 画面の動き、動画の解析の流れ、カメラ |
| `js/analysis.js` | 角度・エラー除去・着地とインパクトの検出（Colabのノートブックと同じ計算） |
| `js/frames.js` | 動画を頭から順番にデコードしてコマを取り出す（WebCodecs。使えない動画は今まで通りの方法） |
| `js/mp4box.all.min.js` | mp4の読み込み（mp4box.js、BSD-3-Clause。`js/mp4box.LICENSE.txt`） |
| `js/firebase.js` | 自動ログインと記録・名簿の保存 |
| `config.js` | Firebaseの設定（自分で貼る） |
| `firestore.rules` | データの権限ルール（Firebaseに貼る） |
| `pose_s/`、`pose_n/` | 骨格推定AI（YOLO11 姿勢推定。標準／速さ優先） |
| `sw.js`、`manifest.webmanifest`、`icons/` | ホーム画面に追加・オフライン用 |

## あとで「選手は自分の記録だけ」に切り替えるとき

選手ごとにログインして、選手は自分の記録だけ、スタッフは全員分を見られる「本番バージョン」も用意してあります（`form-note-team.zip`）。切り替えるときは、Firebaseで「メール / パスワード」のログインを有効にして、本番バージョンのファイルとルールに入れ替えます。仮バージョンで保存した記録は選手の名前で保存されているので、本番バージョンの選手アカウントとひも付ける作業が別に必要です（そのときに手伝います）。
